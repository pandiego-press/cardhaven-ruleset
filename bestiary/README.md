# Cardhaven Bestiary

Community-maintained creature stat blocks for the Cardhaven Ruleset, released under CC BY-SA 4.0.

## Important Exclusion

**Blu Beaks are NOT part of this open bestiary.** They are a proprietary creature of the Cardhaven universe and remain the exclusive intellectual property of M.A. Lionmayne / Pandiego Press. Do not submit Blu Beak stat blocks or lore as contributions — they will not be accepted.

All other creatures published in this folder are open for community adaptation and expansion under CC BY-SA 4.0.

## Scope

Entries may include general creature appearance and behavior (standard bestiary flavor — physical description, hunting tactics, ecology), but do not reference named Three Crowns/Arkturon locations, named characters, or specific plot events — see [CONTRIBUTING.md](../CONTRIBUTING.md).

## Folder Structure

- **cardhaven/** — native-format creature stat blocks for LitRPG authors, using this ruleset's own terms (Rank/Level, XP, Trash Mob/Elite/Boss roles, etc.).
- **conversions/** — tabletop conversions of the same creatures for GMs running other systems (dnd5e, pathfinder2e, shadowdark, draw-steel, nimble). Added in Phase 2.
