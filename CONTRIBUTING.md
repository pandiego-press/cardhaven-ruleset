# Contributing to the Cardhaven Ruleset

Thank you for your interest in contributing. This is a community-maintained mechanical ruleset — we welcome bug fixes, balance suggestions, new card archetypes, and expanded mechanics.

## What We Accept

- Corrections to existing rules (typos, ambiguities, math errors)
- Balance proposals with clear reasoning
- New card templates that fit the existing rarity/type framework
- Expanded crafting recipes
- New creature stat blocks for the Bestiary (see [/bestiary/](bestiary/))
- Translations

## What We Don't Accept

- Lore, worldbuilding, or fiction (the world is not open-source)
- Rule changes that break compatibility with the core Triple Bind economy
- Contributions that don't follow the CC BY-SA 4.0 terms

## How to Contribute

1. Fork this repository
2. Create a branch: `git checkout -b my-contribution`
3. Make your changes with clear commit messages
4. Submit a pull request with a description of what changed and why

## Attribution

By submitting a pull request, you agree that your contribution will be released under CC BY-SA 4.0 and credited in the [CONTRIBUTORS.md](CONTRIBUTORS.md) file.
